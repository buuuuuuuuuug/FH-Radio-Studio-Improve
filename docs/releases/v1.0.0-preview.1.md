# FH Audio Studio 1.0 Preview

本版更新内容如下，计划发布标签为 `v1.0.0-preview.1`。下载包以 Releases 页面正式发布的附件为准。

本版将独立测试的电台台呼、语音替换和音频素材编辑整合到主程序，并重新整理文档、功能介绍与写入流程。

## 主要变化

- **电台台呼**：导入与拖放、原台呼试听、素材池与多选分配；波形裁剪、音量与下一首进入位置编辑，支持前后歌曲衔接试听。台呼与歌曲合并构建、共用 RadioInfo；不提供台呼位置扩容。
- **语音替换**：按分类和语言浏览游戏音频，支持自选文件；备份解析后按条目替换，对照原音、语音语言及显示语言文本。三栏宽度、表格列宽、搜索、多选、文件夹管理及缓存复用已整合。
- **语音素材**：波形选区、插入静音、选区静音／删除、音量、撤销重做；静音默认 100ms，调整步长 50ms。保留原素材，选区操作尽量保留播放指针位置。
- **文本与语言**：文本列跟随概览语言设置，Ctrl＋左键复制；导出支持 TXT、CSV、XLSX、实时预览与自定义字段，也可将原音加入素材池。
- **保存与写入**：草稿切页保留，未保存时提示；语音单独构建与写入。写入窗口列出目标相对路径、大小和作用，可逐文件选择；与游戏一致的文件不再无条件复制进准备包。
- **统一交互**：撤销／重做统一为 Ctrl＋Z／Ctrl＋Y；歌曲、台呼与语音编辑复用窗口布局、播放控件和波形操作。台呼素材删除、池中多选退出、语音 Esc 退出和池中分配按钮排版已修正。
- **功能介绍**：台呼页、语音页及编辑器加入引导；语音页完整介绍为五步，批量工具与保存／构建／写入分别框选。
- **拖入导入**：歌曲、台呼、语音素材池与指定替换条目提供拖入区域提示、转换进度及结果消息。导入错误优先展示文件名和实际原因。
- **稳定性**：处理切页销毁、试听起始／结尾、缓存重复加载、包替换和部分文件占用等问题；单个台呼预览失败不再阻止整页加载。无输入的后台命令会关闭输入管道，避免等待输入结束而停滞。

## 下载与升级

完整解压 Windows x64 便携包，运行 `fh-radio-studio.exe`，不要只复制 EXE。建议先解压到新英文目录再打开已有工程；主程序继续读取原有设置前缀，不预设个人测试工程或歌曲。

准备的附件包括 Windows 便携包、循环引擎对应源码／许可材料及 SHA256 校验清单。AI 可选依赖未全部预装，可先使用“无 AI＋SeamlessLoopMusic”。

## 使用边界

电台扩容、分场景编排继续标记为实验功能，分场景需要先开启扩容。语音资源可否替换取决于实际 bank 格式，游戏事件仍可能控制语音触发与时长；备份和本地重构验证不能替代游戏内听感验证。

构建本身不会写入游戏。歌曲与台呼共用准备包，语音使用独立准备包；写入前退出游戏并核对文件清单。升级不应删除或覆盖个人工程。

## 本地验证

- 应用自动测试：738 项通过，16 项按条件跳过；后端测试：528 项通过。
- 静态检查无问题，Windows Release 构建完成；字体与歌曲／台呼多选工具栏已实际运行核对。
- 便携包在独立目录离线初始化，主命令、台呼及语音命令可运行；窗口正常启动、正常退出，原有用户设置未变化。
- ZIP 完整性、文件散列和后端 wheel 与源码一致性已检查；附件校验值及具体记录随本地审查文件提供。

本轮准备不执行真实游戏写入。尚未覆盖全部 AI 模型、全部 bank 类型、全部语言和所有游戏事件，资源管理器真实拖放仍需人工确认。
